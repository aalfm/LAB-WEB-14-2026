# Alifah Portfolio — React + Vite + Tailwind CSS

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In the terminal, run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite.

## Structure
- `src/App.jsx`: imports and renders the six required components in order.
- `src/components/`: Navbar, Hero, About, Skills, Gallery, Footer.
- `src/assets/gallery/`: project and design images extracted from the supplied portfolio PDF.
- `public/profile.jpg`: profile image.

## Assignment notes
- Uses React + Vite and Tailwind CSS.
- Uses `const` arrays and `.map()` with keys to render lists.
- Navbar menu and Hero button use `onClick` handlers.
- Does not use `useState` or props.
- Update social links in `src/components/Footer.jsx` if your usernames differ.
